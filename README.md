# Streamlit Calculator

A simple calculator built using Python and Streamlit.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero handling

## Requirements
- Python
- Streamlit

## Installation

Install Streamlit:

```bash
pip install streamlit

```

## Run the Application

Start the calculator using:

```bash
streamlit run chatbot.py
```
